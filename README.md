# Landing Page

  This project was created to practice HTML, styling, and responsive web development.

# Live Preview
  - [DEMO LINK](https://artemnosachenko.github.io/landing-page/)

# Technologies Used
  - HTML5
  - SCSS
  - JavaScript
  - Stylelint

# Getting Started
  **Prerequisites**
  - Make sure you have Node.js and npm installed on your computer.

  **Installation**
  1. Clone the repository:
    - git clone https://github.com/ArtemNosachenko/landing-page.git
  2. Navigate to the project directory:
    - cd landing-page
  3. Install the dependencies:
    - npm install
  4. Start the development server:
    - npm start

  - Responsive page layout
